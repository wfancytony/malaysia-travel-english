# 马来西亚旅行英语 · 完整源码包

这是已发布网站的手机适配版本，包含网页源码、课程内容、全部发音音频和配图。

在线地址：https://malaysia-speak-six-days-yimai.wfancytony75058.chatgpt.site/

## 包内内容

- `dist/index.html`：页面结构。
- `dist/styles.css`：电脑与手机样式；700px 及以下使用手机布局。
- `dist/app.js`：场景切换、搜索、听读、慢速播放、跟读、大字卡和本地进度。
- `dist/curriculum.json`：16 个场景、213 条短句及地名卡、13 组对话。
- `dist/audio/`：301 个 M4A 发音文件，包含短句、对话和问路发音。
- `dist/beach.jpg`：海滩配图。
- `.openai/hosting.json`：当前 Sites 网站的静态目录与项目关联配置。

这些 HTML、CSS、JavaScript 文件就是可直接修改的源码，不需要 npm 安装或构建。

## 在电脑本地运行

需要 Python 3。在解压后的 `malaysia-travel-english` 文件夹内打开终端，运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

Windows 如使用 Python Launcher，可改用：

```bat
py -3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

然后在浏览器访问 `http://127.0.0.1:8000`。按 `Ctrl+C` 停止服务。

页面用 fetch 加载课程 JSON，因此直接双击 HTML 文件可能无法加载课程。请通过上面的本地服务，或静态网站托管打开。

## 手机上使用与部署

手机可直接打开在线地址；当前网站为私有访问，如提示登录，使用有权限的 ChatGPT 账号。

若自行部署，把 `dist` 文件夹内的全部文件放到静态网站托管服务，保留 `audio` 子目录及文件名即可。发布目录为 `dist`；这套代码不需要服务器端程序、数据库或 AI API 密钥。

手机布局根据网页窗口宽度自动切换。电脑预览时将窗口缩窄，或在浏览器开发工具中选择手机尺寸。

## 内容和资源说明

- 听读使用包内已生成的音频，慢速及跟读通过浏览器播放控制实现，不会按次调用 AI 语音接口。
- 通过本地服务运行时，课程与发音可从本机读取；在线版本首次加载需要网络。没有预先缓存整个网站的离线功能。
- 地图、名称来源和官方信息链接需要联网。
- 已掌握进度只保存在当前浏览器的 localStorage，不在手机与电脑之间同步；在不同网址打开也分别保存。
- 发音是合成英语示范，地名可同时展示英文文字进行沟通。
- 年龄、航班号等示例应按实际信息替换。
